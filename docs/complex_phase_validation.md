# Complex Phase Validation

## Date: 2026-09-25

## Purpose

Test G=O for states with different complex phases.

## Results

### Bell State with Relative Phase

| φ | G | Diff |
|---|------|------|
| 0 | 0.5000 | 1.11e-16 |
| π/4 | 0.5000 | 1.11e-16 |
| π/2 | 0.5000 | 1.11e-16 |
| π | 0.5000 | 1.11e-16 |
| 3π/2 | 0.5000 | 1.11e-16 |

### General Complex States

| Sample | G | Diff |
|--------|---|------|
| Complex 1 | 0.3066 | 5.55e-17 |
| Complex 2 | 0.2288 | 3.61e-16 |
| Complex 3 | 0.2619 | 2.78e-16 |

## Conclusion

G=O holds for all complex phases. The relative phase φ does not affect
the equality, confirming that G=O depends only on the magnitude of the
Schmidt coefficients.
