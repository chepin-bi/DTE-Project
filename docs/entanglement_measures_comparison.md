# Entanglement Measures Comparison

## Date: 2026-09-25

## Purpose

Compare G (Negativity) with Concurrence for 2×2 systems.

## Results

| State | G | O | C (Concurrence) | C/G |
|-------|---|---|-----------------|-----|
| Bell | 0.5000 | 0.5000 | 1.0000 | 2.0 |
| Werner(p=0.5) | 0.1250 | 0.1250 | 0.2500 | 2.0 |
| Random pure | 0.3983 | 0.3983 | 0.7967 | 2.0 |

## Key Finding

For 2×2 systems:

    C = 2G

This is the well-known relationship between Concurrence and Negativity for
bipartite qubit systems. Since G=O, we also have:

    C = 2O

## Interpretation

1. **Concurrence is twice Negativity** for 2×2 systems
2. **G=O implies** C = 2G = 2O
3. **All three measures are equivalent** up to a constant factor

## Conclusion

The DTE framework's G measure is consistent with established entanglement
measures. The relationship C = 2G confirms that G captures the same
entanglement structure as Concurrence.
