# Cat State Validation

## Date: 2026-09-25

## Purpose

Test G=O for cat states (superpositions of macroscopically distinct states).

## Results

### 4×4 Cat-Like States

| State | G | Diff |
|-------|---|------|
| \|0,0⟩ + \|3,3⟩ | 0.5000 | 1.11e-16 |

### 2×2 Generalized Cat States

| θ | G | Diff |
|---|-----|------|
| 0 | 0.0000 | 0.00e+00 |
| π/6 | 0.4330 | 1.11e-16 |
| π/4 | 0.5000 | 0.00e+00 |
| π/3 | 0.4330 | 0.00e+00 |
| π/2 | 0.0000 | 4.98e-17 |

## Observations

1. **Maximum entanglement at θ=π/4**: G=0.5 (Bell state)
2. **Separable at θ=0 and θ=π/2**: G=0
3. **G=O holds exactly** for all cat states

## Conclusion

G=O holds for cat states in both finite-dimensional approximations and
qubit systems. The equality is independent of the superposition angle.
