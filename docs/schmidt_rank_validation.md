# Schmidt Rank Validation

## Date: 2026-09-25

## Purpose

Test G=O for states with controlled Schmidt rank.

## Results

### 4×4 States

| Schmidt Rank | G | Diff |
|--------------|---|------|
| 1 | 0.3630 | 1.67e-16 |
| 2 | 0.8733 | 1.11e-16 |
| 3 | 0.9330 | 1.11e-16 |
| 4 | 1.2870 | 4.44e-16 |

## Observations

1. **G increases with Schmidt rank**
   - Higher Schmidt rank → more entanglement

2. **G=O holds exactly** for all Schmidt ranks

3. **Rank-1 states can have G>0**
   - Pure states with unequal Schmidt coefficients are entangled

## Conclusion

G=O is independent of Schmidt rank. The equality holds for all levels of
entanglement complexity.
