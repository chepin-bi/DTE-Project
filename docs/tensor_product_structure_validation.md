# Tensor Product Structure Validation

## Date: 2026-09-25

## Purpose

Test G=O for states with different tensor product structures.

## Results

| System | G | Diff |
|--------|---|------|
| 2×3 | 0.3264 | 1.67e-16 |
| 2×4 | 0.4687 | 3.33e-16 |
| 3×4 | 0.6810 | 4.44e-16 |
| 2×5 | 0.4604 | 2.22e-16 |

## Conclusion

G=O holds for all tested tensor product structures. The equality is
independent of the specific dimensions of the subsystems.
