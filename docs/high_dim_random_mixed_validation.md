# High-Dimensional Random Mixed States

## Date: 2026-09-25

## Purpose

Statistically validate G=O for random mixed states in high dimensions.

## Results

| Dimension | max G | max Diff | Pass Rate |
|-----------|-------|----------|-----------|
| 3×3 | 0.0969 | 2.43×10⁻¹⁶ | 10/10 |
| 4×4 | 0.1130 | 1.94×10⁻¹⁶ | 10/10 |
| 5×5 | 0.0871 | 2.36×10⁻¹⁶ | 10/10 |
| 6×6 | 0.0819 | 2.50×10⁻¹⁶ | 10/10 |

## Conclusion

G=O holds with machine precision for random mixed states in dimensions up
to 6×6. All 40 tested states pass with maximum difference < 3×10⁻¹⁶.
